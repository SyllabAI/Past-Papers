# SyllabAI Official Source Corpus — Multi-Agent Rules

The project-wide multi-agent operating system is canonical in `SyllabAI/syllabai` (`AGENT.md` + `.syllabai/`).

This repository is source corpus, not application logic.

1. Preserve official source files, source identity, checksums and provenance.
2. Never infer or silently repair ambiguous paper/session identity.
3. Keep acquisition/source changes separate from normalized `syllabai-pastpapers` data transformations.
4. Any source replacement must preserve an auditable reason and checksum/provenance trail.
5. Record task ID, base commit and corpus evidence for material changes.
6. Do not treat raw source content as validated learner-servable assessment content; downstream validation gates remain authoritative.
